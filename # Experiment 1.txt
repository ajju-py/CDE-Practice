# Experiment 1 – Cloud Storage

**Aim:** Create a cloud storage bucket and upload a dataset (CSV/JSON). Demonstrate basic operations such as upload, download, and file organization using Amazon S3/Azure Blob Storage.

## Solution

**Platform Used:** Amazon Web Services (AWS) – Amazon S3.

### 1. Introduction

Amazon S3 (Simple Storage Service) is an object storage service provided by AWS. It allows users to store, retrieve, and manage files over the internet. It stores data in containers called buckets.

### 2. Procedure

**Step 1: Open AWS Management Console**
1. Open https://console.aws.amazon.com/
2. Log in to your AWS account.
3. Search for Amazon S3.
4. Open the S3 service.

**Step 2: Create a Bucket**
1. Click on Create Bucket.
2. Enter the bucket name: `ajay-cloud-storage-practical-2026`.
3. Select the AWS Region: Asia Pacific (Mumbai).
4. Keep Block Public Access enabled.
5. Keep default encryption enabled.
6. Click Create Bucket.

**Step 3: Create a CSV Dataset**

Create a file named `students.csv` with the following data:

```csv
Student_ID,Name,Department,Marks
101,Ajay,CSE,85
102,Rahul,IT,90
103,Priya,CSE,88
104,Amit,ENTC,78
105,Neha,CSE,92
```

**Step 4: Upload the Dataset**
1. Open the created bucket.
2. Click Upload.
3. Select Add Files.
4. Choose the `students.csv` file.
5. Click Upload.
6. Verify that the file is uploaded successfully.

**Step 5: Organize Files**
1. Open the bucket.
2. Click Create Folder.
3. Enter the folder name `datasets`.
4. Open the folder.
5. Upload the `students.csv` file inside it.

The folder structure will be:

```text
ajay-cloud-storage-practical-2026/
    |
    └── datasets/
          └── students.csv
```

**Step 6: Download the Dataset**
1. Open the datasets folder.
2. Select `students.csv`.
3. Click Download.
4. Save the file to your computer.
5. Open the downloaded file and verify its contents.

**Step 7: Verify the Dataset**

Check the uploaded file name, file size, storage class, and downloaded file contents.

### 3. AWS CLI Commands (Optional)

Configure AWS CLI:

```bash
aws configure
```

Create a bucket:

```bash
aws s3 mb s3://my-cloud-practical-2026 --region ap-south-1
```

Upload a file:

```bash
aws s3 cp students.csv s3://my-cloud-practical-2026/datasets/students.csv
```

List uploaded files:

```bash
aws s3 ls s3://my-cloud-practical-2026/datasets/
```

Download a file:

```bash
aws s3 cp s3://my-cloud-practical-2026/datasets/students.csv downloaded_students.csv
```

### 4. Expected Output

1. Successfully created an Amazon S3 bucket.
2. Successfully uploaded the CSV dataset.
3. Created a folder named datasets.
4. Organized the uploaded file inside the folder.
5. Successfully downloaded the dataset.
6. Verified the downloaded file.

### 5. Result

Successfully created a cloud storage bucket using Amazon S3, uploaded a CSV dataset, organized files using folders, and performed basic upload and download operations.

### 6. Conclusion

Amazon S3 provides a reliable and scalable cloud storage solution. The practical demonstrated basic cloud storage operations, including bucket creation, file uploading, downloading, and file organization.
